# ArabScope Mobile News Portal

本项目为移动端高保真静态新闻网页，根据图1（Gulf News手机版布局）与图2（ArabScope品牌Logo）像素级复刻打造。

## 目录结构
- index.html        # 静态页主入口（Semantic HTML5）
- css/style.css     # 纯CSS3响应式移动端样式系统
- js/app.js         # 抽屉导航、搜索栏、一键复制、关注交互与阅读进度条
- images/logo.png   # ArabScope高清透明Logo（取自图2）
- images/hero.jpg   # 会议头图
- package.json      # 便捷预览脚本配置

## 预览与运行
1. 直接用任意浏览器打开 index.html 即可完整浏览所有交互与页面效果。
2. 或在项目目录下运行 npm run dev 或 pnpm dev，在 http://localhost:3000 预览。
